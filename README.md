# LitePainter
Texture painter 3D ringan (C++ / OpenGL 3.3).
Tahap 8: Smart Masks (drag & drop ke layer), MG Mask Editor (generator bertumpuk + procedural noise), Smart Material baru dengan bake otomatis.

Alat: B Brush | G Fill | P Path | R Ribbon
Kiri = pakai alat | Alt+Kiri = orbit | Kanan/Tengah/Shift+Kiri = pan | Scroll = zoom
[ ] ukuran brush | E eraser | X symmetry | F frame | Ctrl+Z / Ctrl+Y undo/redo
Smart Mask: tab Mask -> tarik ke layer di panel kanan. Smart Material: tab Material.
