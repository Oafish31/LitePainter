# LitePainter
Texture painter 3D ringan (C++ / OpenGL 3.3).
Tahap 5: baking AO + Curvature (multi-thread, BVH), UI baru dengan panel dan tab.

Kiri = cat | Alt+Kiri = orbit | Kanan/Tengah/Shift+Kiri = pan | Scroll = zoom
[ ] = ukuran brush | E = eraser | X = symmetry | F = frame model | Ctrl+Z / Ctrl+Y = undo/redo
